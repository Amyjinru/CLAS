## ADDED Requirements

### Requirement: 可移植的数据库初始化与升级
系统 MUST 提交完整建表脚本、按顺序执行的增量迁移脚本和独立的测试数据脚本。README MUST 区分空库初始化与已有库升级流程。

#### Scenario: 初始化空数据库
- **WHEN** 在官方 MySQL 容器上执行空库初始化流程
- **THEN** 所有业务表、索引和必要初始数据创建成功，应用可通过健康检查

#### Scenario: 升级已有数据库
- **WHEN** 在已有历史数据的数据库上按 README 顺序执行迁移
- **THEN** 新表和字段被补齐，已有业务数据不被完整建表脚本覆盖或删除

### Requirement: 迁移可验证且失败可诊断
系统 MUST 提供迁移检查或测试脚本，验证迁移顺序、重复执行与测试数据导入结果；迁移失败 MUST 阻止依赖该数据库的部署继续。

#### Scenario: 迁移校验失败
- **WHEN** 迁移脚本执行失败或版本状态不一致
- **THEN** 初始化/部署步骤失败，输出失败脚本与数据库诊断信息，应用工作负载不得标记为就绪
