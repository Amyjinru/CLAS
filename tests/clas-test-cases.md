# 测试用例：CLAS 外卖网站

## 概述
- **项目**: CLAS (校园本地外卖+团购+到店服务平台)
- **技术栈**: Spring Boot + MyBatis Plus + MySQL | Vue 3 + Element Plus + Vite
- **认证**: JWT Bearer Token (BCrypt 密码哈希)
- **测试范围**: 功能测试 / 边界测试 / 错误处理 / 状态转换
- **最后更新**: 2026-06-11

---

## 1. 用户注册与认证

### TC-F-001: 用户注册成功
- **优先级**: High
- **前置条件**: 手机号未注册
- **测试步骤**:
  1. 发送 POST `/api/user/register`，body: `{"phone":"13900000001","password":"Test1234","nickname":"测试用户"}`
  2. 验证响应
- **预期结果**: code=200, data 包含用户信息(不含密码), 密码以 BCrypt 哈希存储
- **后置条件**: 数据库 user 表新增一行, password 字段以 `$2a$` 开头

### TC-F-002: 用户登录成功并获取 JWT
- **优先级**: High
- **前置条件**: 用户 13800000001 存在
- **测试步骤**:
  1. 发送 POST `/api/user/login`，body: `{"phone":"13800000001","password":"Abc123!"}`
  2. 验证响应包含 token
- **预期结果**: code=200, data.token 非空, token 格式为 JWT (三段 base64)
- **后置条件**: 可使用该 token 访问受保护接口

### TC-F-003: 获取当前用户资料
- **优先级**: High
- **前置条件**: 已登录, 持有有效 JWT
- **测试步骤**:
  1. 发送 GET `/api/users/me`，Header: `Authorization: Bearer <token>`
- **预期结果**: code=200, data 包含 phone/nickname/avatar/username

### TC-ERR-001: 未登录访问受保护接口返回 401
- **优先级**: High
- **前置条件**: 无
- **测试步骤**:
  1. 不携带 Authorization Header, 发送 GET `/api/users/me`
- **预期结果**: HTTP 401, 不返回用户数据

### TC-ERR-002: 使用手机号直接认证被拒绝
- **优先级**: High
- **前置条件**: 用户 13800000001 存在
- **测试步骤**:
  1. 发送 GET `/api/users/me`，Header: `Authorization: 13800000001`
- **预期结果**: HTTP 401, 系统拒绝 phone-number 认证方式

### TC-ERR-003: 过期/伪造 Token 被拒绝
- **优先级**: Medium
- **前置条件**: 无
- **测试步骤**:
  1. 发送 Header `Authorization: Bearer invalid.jwt.token`
- **预期结果**: HTTP 401

### TC-ERR-004: 注册已存在手机号
- **优先级**: Medium
- **前置条件**: 手机号 13800000001 已注册
- **测试步骤**:
  1. 发送 POST `/api/user/register`，body 使用已存在手机号
- **预期结果**: code≠200, message 提示手机号已注册

### TC-F-004: 修改昵称
- **优先级**: Medium
- **前置条件**: 已登录
- **测试步骤**:
  1. 发送 PUT `/api/users/me/profile`，body: `{"nickname":"新昵称"}`

### TC-F-005: 上传头像
