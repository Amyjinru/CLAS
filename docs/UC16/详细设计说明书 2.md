# UC16 详细设计说明书

## 配送状态机

```text
商家接单 → AVAILABLE
AVAILABLE --骑手原子领取--> ASSIGNED_WAITING_MEAL
ASSIGNED_WAITING_MEAL --取餐--> DELIVERING
DELIVERING --送达--> DELIVERED
ASSIGNED_WAITING_MEAL --骑手放弃--> AVAILABLE
ASSIGNED_WAITING_MEAL --用户取消--> 取消并释放骑手
```

所有状态转换均在服务层校验订单归属和当前状态；取餐后的放弃被拒绝。

## 调度与 ETA

1. 任务查询限制骑手当前位置至商家五公里以内。
2. 领取使用条件更新，要求订单仍为 `AVAILABLE`、骑手已审核/上线/开始接单且未超过容量。
3. 高德路线可用时计算骑手至商家再至用户的预计时间；不可用时改用直线距离估算，仍返回可解释的降级标记。
4. 承诺送达时间以商家接单时快照为准，后续 ETA 变化不延后逾期判定。

## 结算与幂等

| 事件 | 记录 | 幂等约束 |
| --- | --- | --- |
| 骑手送达 | 待结算佣金 | 订单/来源唯一 |
| 用户确认 | 佣金、小费转可提现 | 已结算来源不重复处理 |
| 用户打赏 | 1—5000 分的小费 | 每订单一次及幂等键 |
| 超时扫描 | 异常、5 分绩效扣分、20% 佣金扣减 | 订单超时异常唯一 |
| 提现 | 可提现转冻结，管理员审核 | 仅 `PENDING` 提现可审核 |

## 对话与隐私

对话使用 `chat_conversation` 与订单绑定。送达后只读；消息发送前依次经过本地违规词、可选 AI 审核及 AI 故障降级。隐私通话会话有效十分钟，保存审计记录，不返回用户完整电话。
