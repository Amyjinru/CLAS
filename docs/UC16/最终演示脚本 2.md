# UC16 最终演示脚本

## 演示准备

1. 确认云端已执行 `database/migration-*.sql`，并配置 `RIDER_IDENTITY_ENCRYPTION_KEY`、高德 Key（可选）与演示登录开关。
2. 打开 GitHub Actions 最新成功运行页、项目看板及当天截图，作为工程证据。
3. 准备用户、商家、骑手和管理员四个浏览器会话；使用 README 的基础账号或登录页“获得权限”中的演示入口。

## 主线（约 6 分钟）

1. 用户浏览商家、下单并完成模拟支付。
2. 商家接单，说明备餐时间快照和订单变为可配送。
3. 骑手上线、重新定位、点击“开始接单”，按智能排序领取订单。
4. 骑手展示配送中订单、联系商家/用户与脱敏电话入口，随后取餐并送达。
5. 用户订单页展示骑手位置与 ETA，确认收货、可选打赏并给骑手评价。
6. 骑手个人中心展示收入流水、用户评价和日表现；管理员展示骑手审核/提现或异常记录。

## 异常点演示（任选 2 项）

- 未开始接单的骑手领取任务被拒绝。
- 第二名骑手重复领取同一任务被拒绝。
- 用户在送达后继续发送骑手消息被拒绝但可查看历史。
- 任务超过承诺时间只生成一次异常，订单不被自动取消。

## 收尾证据

展示 `mvn test`、`npm run build`、CI 成功记录和对应测试/PR/看板截图；说明所有金额以分存储、通话和提现均为课程演示模拟能力。
