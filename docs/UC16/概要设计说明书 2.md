# UC16 概要设计说明书

## 架构与职责

```text
Vue 用户/商家/骑手/管理员页面
        │ Bearer Token + activeRole
Spring Controller → Service → Mapper → MySQL
        ├─ 调度与状态机：骑手任务、领取、取餐、送达、放弃
        ├─ 路线与追踪：高德路线、位置历史、ETA、承诺窗口
        ├─ 协作与隐私：订单会话、脱敏通话会话、通知
        └─ 财务与治理：佣金、打赏、评价、提现、超时、日指标
```

## 主要组件

| 组件 | 职责 |
| --- | --- |
| `RiderDispatchService` | 骑手上线、开始/结束接单、附近任务、原子领取、容量与排序。 |
| `RiderDeliveryService` | 取餐、送达、取餐前放弃、配送状态机和 ETA 更新。 |
| `RiderLocationService` | 校验在线骑手的位置上报、历史记录与订单追踪授权。 |
| `RiderContactService` / `RiderMerchantContactService` | 用户—骑手、骑手—商家订单会话及隐私通话。 |
| `RiderSettlementService` / `RiderWithdrawalService` | 佣金、小费、确认结算、提现冻结与管理员审核。 |
| `RiderPerformanceService` | 超时异常、日指标与绩效评分。 |

## 状态设计

| 业务对象 | 关键状态 |
| --- | --- |
| 配送 | `AVAILABLE`、`ASSIGNED_WAITING_MEAL`、`DELIVERING`、`DELIVERED` |
| 骑手工作 | `onlineStatus` 与 `acceptingOrders` 独立；结束接单仅停止新任务。 |
| 资金 | `PENDING`、`WITHDRAWABLE`、`FROZEN`，以结算记录为准。 |

## 安全边界

- JWT 的 active role 决定接口权限，不能由请求参数提升角色。
- 身份证号加密存储、默认脱敏，管理员查看全文须审计。
- 位置、对话、电话均以订单归属和配送状态为边界；通话仅展示脱敏号码。
