# 主路径联调指南

> 目标：在本地同时跑 **iam / merchant / catalog / order / compat**，经 **Nginx :8080** 统一入口，前端 `npm run dev` 走主路径。

## 1. 前置条件

| 组件 | 说明 |
| --- | --- |
| JDK 17+ | 运行五个 Spring Boot jar |
| Maven 3.9+ | `services/` 下构建 |
| MySQL 8 | 库名 `clas` |
| Redis | 验证码；本地可用 Docker / Memurai |
| Nginx（推荐） | 网关 `8080`；未安装时可用 `-Direct` 冒烟 |
| Node 18+ | 前端 dev |

## 2. 配置环境

```powershell
cd services/scripts
copy env.local.example env.local
# 编辑 env.local：至少填写 MYSQL_PASSWORD
```

建议同时设置：

- `JWT_SECRET` — 五服务必须一致，**勿用**已被禁用的开发默认值
- `CLAS_INTERNAL_API_KEY` — 五服务必须一致的随机内部接口密钥；未配置时所有 `/internal/**` 请求会被拒绝
- `CLAS_VERIFICATION_FIXEDCODE=123456` — 登录/注册可填固定验证码
- `CLAS_DEMO_ACCOUNTS_ENABLED=true` — 演示快捷登录

## 3. 初始化数据库

**推荐（联调环境一键重建）：**

```powershell
cd services/scripts
.\bootstrap-db.ps1
```

脚本会：删除并重建 `clas` 库 → 导入 `database/schema.sql` → 依次导入 `database/seed-*.sql` → 补丁 `user_role` 扩展列。

若库是旧版单体遗留、缺列报错，也可在备份后执行 `bootstrap-db.ps1`，或按需跑 `database/migration-*.sql`（Windows 用 `migrate-db.ps1`，需 cmd 重定向）。

## 4. 一键启动

```powershell
cd services/scripts
.\start-services.ps1
```

脚本会：

1. 加载 `env.local`
2. `mvn package -DskipTests`（可用 `-SkipBuild` 跳过）
3. 后台启动五个 jar（日志 `services/logs/`）
4. 若检测到 `nginx`，加载 `services/nginx/clas-gateway.conf` 监听 **8080**
5. 等待五服务 `/api/health` 就绪

停止：`.\stop-services.ps1`

## 5. 网关路由（:8080）

| 前缀 | 服务 |
| --- | --- |
| `/api/user` `/api/address` `/api/favorites` `/api/role-applications` `/api/notifications` | iam :8081 |
| `/api/merchant`（不含 products） `/uploads/merchant-logo` | merchant :8085 |
| `/api/merchant/me/products` `/api/merchant/products` `/api/product` `/api/bookings` `/uploads` | catalog :8082 |
| `/api/deals`（列表/详情/merchant） | catalog |
| `/api/deals/mine` `/api/deals/orders` `/api/deals/redeem` `/*/buy` | order |
| `/api/cart` `/api/order` `/api/payment` `/api/coupon` `/api/review` | order :8083 |
| `/api/rider` `/api/delivery` `/api/chat` `/api/admin` `/api/announcement` `/api/public` | compat :8084 |

前端 `frontend/vite.config.js` 已把 `/api`、`/uploads` 代理到 `http://localhost:8080`。

```powershell
cd frontend

```

## 6. 冒烟测试

**无 Nginx（按服务端口直连，推荐本地先跑通）：**

```powershell
cd services/scripts
.\smoke-main-path.ps1 -Direct
```

**经网关（需 Nginx 监听 8080）：**

```powershell
.\smoke-main-path.ps1
```

覆盖：四服务 health → 登录 → 商家/商品 → 购物车 → 团购 → 公告 → 公开统计 → 管理员 dashboard。

登录使用固定 `deviceId` + 验证码 `123456`（需 `CLAS_VERIFICATION_FIXEDCODE`）。

### 共享联调留证（#47）

若本机 Docker Engine 可用，且 `3306`、`6380`、`8080-8085` 未被占用，可运行：

```powershell
cd services/scripts
.\run-shared-integration.ps1
```

脚本使用随机临时密码启动 `clas-integration-mysql` 和 `clas-integration-redis`，复用数据库初始化、五服务启动和网关冒烟脚本，并在 `docs/evidence/` 写入脱敏结果。无论成功或失败，脚本只清理自己创建的临时容器及服务进程，不会停止其他容器。

该证据只代表本机 Docker 联调；Kubernetes 服务发现、依赖故障注入和恢复仍须在集群中按 #44 验收。订单私有 schema 与退款/幂等异常回归分别见 #49、#50。

## 8. 故障排查

| 现象 | 处理 |
| --- | --- |
| 启动失败 `JWT_SECRET` | 在 `env.local` 使用非禁用密钥（见 `env.local.example`） |
| 登录 500 / 缺列 | 执行 `bootstrap-db.ps1` 或补 migration |
| 商家列表 503 | order internal API 不可用，查 `8083` 日志与 DB `orders` 表结构 |
| 商家列表 500 `LocalDateTime` | 确保已编译含 JSR310 的 `clas-common` 并重启 |
| 网关 502 / nginx 启动失败 | Windows 需在 `services/nginx/logs/` 下创建 `client_body_temp` 等 temp 子目录（`start-services.ps1` 已自动创建） |
| 路径含空格 | 启动脚本已用相对 jar 路径，工作目录为 `services/` |
| 无 Nginx | 前端需网关时安装 nginx；否则 dev 时可改 vite 代理或只用 `-Direct` 冒烟 |
