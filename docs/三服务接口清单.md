# CLAS 三业务微服务接口清单（路由归属）

> 对外路径保持不变；完整接口族见 `docs/microservice-design.md` §4。下表为**当前拆分方案**下的归属。

## clas-iam

| 路径前缀 | 说明 |
| --- | --- |
| `/api/user/**` | 登录、注册、资料、银行卡 |
| `/api/address/**` | 收货地址 |
| `/api/favorites/**` | 收藏 |
| `/api/role-applications/**` | 角色申请 |
| `/api/notifications/**` | 站内通知 |

## clas-catalog

| 路径前缀 | 说明 |
| --- | --- |
| `/api/merchant/**` | 商家列表、入驻、审核、经营 |
| `/api/product/**` | 商品列表、分类、上传 |
| `/api/bookings/**` | 服务预约 |
| `GET /api/deals`、`GET /api/deals/{id}`、`/api/deals/merchant/**` | 团购浏览、详情与商家端发布/管理 |
| `/uploads/**` | 商品/商家图片静态文件 |

## clas-order

| 路径前缀 | 说明 |
| --- | --- |
| `/api/cart/**` | 购物车 |
| `/api/order/**` | 订单、退款、时间线 |
| `/api/payment/**` | 支付 |
| `/api/coupon/**` | 优惠券 |
| `/api/deals/{id}/buy`、`/api/deals/mine`、`/api/deals/redeem`、`/api/deals/redeem-logs`、`/api/deals/orders/**` | 用户买券、核销、支付与退款；其余团购读路径归 catalog |
| `/api/review/**` | 评价 |

## clas-compat

| 路径前缀 | 说明 |
| --- | --- |
| `/api/rider/**` | 骑手 |
| `/api/delivery/**` | 配送跟踪 |
| `/api/chat/**` | 消息 |
| `/api/admin/**` | 管理后台聚合 |
| `/api/announcement/**` | 平台公告 |
| `/api/public/**` | 公开统计（若未下沉到 catalog） |

## 内部接口（服务间）

| 服务 | 前缀 |
| --- | --- |
| iam | `/internal/iam/v1/**` |
| catalog | `/internal/catalog/v1/**` |
| order | `/internal/order/v1/**` |
| compat | `/internal/compat/v1/**` |

所有 `/internal/**` 均要求 `X-CLAS-Service` 和 `X-CLAS-Internal-Key`；网关不转发该前缀。
`compat` 的公开统计通过 `GET /internal/catalog/v1/stats/public` 与 `GET /internal/iam/v1/stats/public` 聚合，不直接查询目录或账户表。
骑手与商家沟通的商家身份校验通过 `GET /internal/catalog/v1/users/{userId}/merchant-id` 完成。
catalog、order、compat 的外部 JWT 校验通过 `GET /internal/iam/v1/users/{userId}/auth-state` 读取会话、已授权角色与账户限制状态，不直接访问 IAM 表。
