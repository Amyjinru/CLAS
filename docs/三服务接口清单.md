# CLAS 三业务微服务接口清单（路由归属）

> 对外路径保持不变；完整接口族见 `docs/microservice-design.md` §4。下表为**当前拆分方案**下的归属。  
> 写隔离：各服务只写自己的表（账号 `clas_*_app`），跨域一律内部 API。见 `docs/服务数据写隔离.md`。

## 内部接口（服务间）

| 服务 | 前缀 |
| --- | --- |
| iam | `/internal/iam/v1/**` |
| merchant | `/internal/merchant/v1/**` |
| catalog | `/internal/catalog/v1/**` |
| order | `/internal/order/v1/**` |
| compat | `/internal/compat/v1/**` |

所有 `/internal/**` 均要求 `X-CLAS-Service` 和 `X-CLAS-Internal-Key`；网关不转发该前缀。
`compat` 的公开统计通过 `GET /internal/merchant/v1/stats/public`、`GET /internal/catalog/v1/stats/public` 与 `GET /internal/iam/v1/stats/public` 聚合。
骑手与商家沟通的商家身份校验通过 `GET /internal/merchant/v1/users/{userId}/merchant-id` 完成。
catalog、order、compat、merchant 的外部 JWT 校验通过 `POST /internal/iam/v1/auth/validate` 提交 Bearer Token。

IAM 管理与角色内部 API（#36，compat 不得再写 `user` / `user_role` / `user_penalty` / `appeal`）：

| --- | --- |

| PUT | `/internal/iam/v1/users/{id}/roles/{role}/status` |
| POST | `/internal/iam/v1/admin/penalties`、`/admin/penalties/{id}/revoke`、`/admin/users/{id}/restore` |
| GET | `/internal/iam/v1/admin/appeals` |
| POST | `/internal/iam/v1/admin/appeals/{id}/process` |
| GET | `/internal/iam/v1/bank-cards/{id}/owned` |

商家统计内部 API：`GET /internal/merchant/v1/stats/admin`、`GET /internal/merchant/v1/merchants/top-by-score`。
