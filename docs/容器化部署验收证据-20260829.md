## 最新迁移故障与修复

Run #254 的测试和镜像阶段成功，但数据库迁移 Job 失败，线上安全保留上一成功版本。服务器日志显示，迁移脚本在 `set -o pipefail` 下用 `echo | grep -q` 查询较长迁移历史时触发 SIGPIPE，导致已执行 SQL 被误判为待执行。

修复后，迁移历史加载到 Bash 关联数组中判断，不再使用会触发 SIGPIPE 的管道。新的 `main` 流水线负责再次验证迁移、rollout 和公网健康。
