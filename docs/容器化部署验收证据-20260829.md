## 5. 2026-08-29 最新部署故障诊断

Run #254 的测试和镜像发布成功，但数据库迁移 Job 失败，线上继续保持上一成功版本 `a4bdad9a...`，没有切换到不健康版本。服务器日志确认根因是迁移历史判断在 `set -o pipefail` 下使用 `echo | grep -q`：历史记录较多时触发 SIGPIPE，导致已执行 SQL 被误判为待执行。

本次修复将迁移历史加载为 Bash 关联数组，避免管道和 SIGPIPE；修复完成后需由新的 `main` 流水线再次验证迁移、rollout 与公网健康检查。
