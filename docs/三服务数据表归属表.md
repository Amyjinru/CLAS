# CLAS 三业务微服务数据表归属表

> 主写权 = 唯一允许 INSERT/UPDATE/DELETE 的服务。其他服务仅保存外键 ID，通过 API 访问。  
> 物理库仍共用 MySQL 库 `clas`（过渡态）。**2026-09-01 起商家表归属 `clas-merchant`（:8085），目录表归属 `clas-catalog`（:8082）。**

## 禁止示例

- order / catalog / compat **不得** 注入 `MerchantMapper`。
- 下单需商品信息 → 调用 catalog 内部 API；需商家营业状态 → 调用 merchant 内部 API，见 `docs/跨服务调用与失败处理.md`。
