## 禁止示例

- order / catalog / iam / compat **不得** 注入 `MerchantMapper`；商家读写一律 `/internal/merchant/v1/**`。
- 下单需商品信息 → catalog 内部 API；需商家营业状态 → merchant 内部 API，见 `docs/跨服务调用与失败处理.md`。
- compat **不得** 直接读写 `orders`、`order_item`、`order_lifecycle_event`、`order_refund_dispute`、`user`、`user_role`、`user_penalty`、`appeal`、`user_bank_card`、`review`、`payment`、`product`、`merchant`；骑手履约写一律 `/internal/order/v1`，Admin/统计/聊天读一律各 owner 内部查询 API。

## compat 订单写路径（#49 已清零）

骑手履约写入已改为 `clas-order` `/internal/order/v1` 配送命令，compat **不再** INSERT/UPDATE/DELETE 这四张表：

| 原直写 | 现内部命令 |
| --- | --- |
| `RiderService.claim` | `POST /deliveries/{id}/claim` mode=`PREPARING` |
| `RiderDispatchService.claim` | `POST /deliveries/{id}/claim` mode=`AVAILABLE` |
| `RiderDispatchService.reorder` | `PUT /riders/{riderId}/delivery-sequence` |
| `RiderDeliveryService` 取餐/送达/放弃 | `POST /deliveries/{id}/pickup|complete|abandon` |
| `DeliveryTrackingService` ETA | `POST /deliveries/{id}/predicted-arrival` |
| `OrderLifecycleService.record` / 骑手评价 | `POST /lifecycle-events` |

`OrdersMapper` 自定义写方法已删。

**compat 跨域读（#36 已清零）：** Admin/统计/聊天/结算/骑手对 `orders` / `order_item` / `review` / `user*` / `merchant` / `product` 的 SELECT 已改为内部查询 API。物理 MOVE 到 `clas_order` 的剩余前置是 P3 拆库脚本与账号切换，不再被跨域 Mapper 挡住。

**订单写隔离（#49）已实施**：账号 `clas_order_app` / `clas_app`，脚本 `database/isolate-order-privileges.sql`，回滚 `database/rollback-order-privileges.sql`。空库 `clas_order` 已创建，表仍在 `clas`。
