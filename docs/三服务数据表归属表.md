# CLAS 业务微服务数据表归属表

> 主写权 = 唯一允许 INSERT/UPDATE/DELETE 的服务。其他服务仅保存外键 ID，通过 API 访问。  
> 冻结基线：`main@51e45fb`（独立 `clas-merchant` :8085）。  
> 物理库现阶段仍共用 MySQL 库 `clas`（逻辑隔离）。**#36 P3 已落地各服务最小权限账号**（表尚未 MOVE）：`clas_*_app` 只写自己的表，`clas_app` 全表仅 SELECT。空库 `clas_iam` / `clas_merchant` / `clas_catalog` / `clas_order` / `clas_compat` 已建。操作见 `docs/服务数据写隔离.md`。  
> **#36 跨域 Mapper 已清零**：compat Admin/统计/骑手/聊天不再 SELECT/写入 iam、merchant、catalog、order 表，一律走内部 API。

## 禁止示例

- order / catalog / iam / compat **不得** 注入 `MerchantMapper`；商家读写一律 `/internal/merchant/v1/**`。
- 下单需商品信息 → catalog 内部 API；需商家营业状态 → merchant 内部 API，见 `docs/跨服务调用与失败处理.md`。
- compat **不得** 直接读写 `orders`、`order_item`、`order_lifecycle_event`、`order_refund_dispute`、`user`、`user_role`、`user_penalty`、`appeal`、`user_bank_card`、`review`、`payment`、`product`、`merchant`；骑手履约写一律 `/internal/order/v1`，Admin/统计/聊天读一律各 owner 内部查询 API。

## compat 订单写路径（#49 已清零）

骑手履约写入已改为 `clas-order` `/internal/order/v1` 配送命令，compat **不再** INSERT/UPDATE/DELETE 这四张表：

| 原直写 | 现内部命令 |
| --- | --- |
| `RiderService.claim` | `POST /deliveries/{id}/claim` mode=`PREPARING` |
| `RiderDispatchService.claim` | `POST /deliveries/{id}/claim` mode=`AVAILABLE` |
| `RiderDispatchService.reorder` | `PUT /riders/{riderId}/delivery-sequence` |
| `RiderDeliveryService` 取餐/送达/放弃 | `POST /deliveries/{id}/pickup|complete|abandon` |
| `DeliveryTrackingService` ETA | `POST /deliveries/{id}/predicted-arrival` |
| `OrderLifecycleService.record` / 骑手评价 | `POST /lifecycle-events` |

`OrdersMapper` 自定义写方法已删。

**compat 跨域读（#36 已清零）：** Admin/统计/聊天/结算/骑手对 `orders` / `order_item` / `review` / `user*` / `merchant` / `product` 的 SELECT 已改为内部查询 API。物理 MOVE 不再被跨域 Mapper 挡住。

## 物理私有 schema 与最小权限账号（P3）

**账号隔离已实施，表尚未 MOVE**：脚本 `database/isolate-service-privileges.sql`，回滚 `database/rollback-service-privileges.sql`，说明 `docs/服务数据写隔离.md`。

当前共享库初始化顺序（`services/scripts/bootstrap-db.ps1`）：

`schema.sql` → `user_role` 补丁 → rider/order 迁移 → `seed-*.sql` →（可选）`isolate-service-privileges.ps1`

| 顺序 | 空库 | 账号 | 状态 |
| --- | --- | --- | --- |
| 1 | `clas_iam` | `clas_iam_app` | 账号已 GRANT 本域表 |
| 2 | `clas_merchant` | `clas_merchant_app` | 同上 |
| 3 | `clas_catalog` | `clas_catalog_app` | 同上 |
| 4 | `clas_order` | `clas_order_app` | #49 已有；P3 纳入同一脚本 |
| 5 | `clas_compat` | `clas_compat_app` | 账号已 GRANT 本域表 |

`clas_app` 在 P3 后对 `clas` 全表仅 SELECT。集群 ConfigMap 默认仍是 `MYSQL_USER=clas`，未跑 isolate 前不要改。共享联调环境与端到端证据见 **#47**。
